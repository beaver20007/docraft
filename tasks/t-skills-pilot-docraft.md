## Приёмка — фактом

1. `powershell C:\Projects\project-method\bootstrap\Get-SkillMatches.ps1` — шортлист top-N с
   колонкой `matched` (объяснение попадания).
2. Шортлист сверен с `~/.claude/skills` — коллизий с `method-bootstrap` / `handoff-protocols` нет.
3. `npx skills add <owner/repo> --skill <имена> --agent claude-code --copy -y` из корня DoCraft.
4. `.gitignore` несёт пару `.claude/*` + `!.claude/skills/`; `git check-ignore <SKILL.md>` →
   exit 1 для каждого установленного скилла.
5. `git status --short` чист, коммит и пуш.
6. На СЛЕДУЮЩЕМ старте сессии — перечислить доступные скиллы, подтвердить присутствие
   установленных дословно.
